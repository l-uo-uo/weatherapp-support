乡镇级精准天气 · 大字清晰 · 免费查询

【天气准】由深圳市活力智汇科技有限公司开发，是一款面向日常出行的天气查询工具，支持城市与乡镇级实时天气、逐小时预报、气象预警、空气质量与生活指数。无需注册账号、无会员内购，安装后即可使用。最低支持 iOS 15。

第一次使用

打开App后，默认展示已添加城市的天气。您可以在城市管理页面手动添加城市或乡镇；也可以允许定位权限，让App自动匹配当前所在位置。App不会默认开启任何权限，权限仅在您使用对应功能时才会弹窗申请。

常见问题

1. 定位后天气不是当前城市怎么办？

  • 系统设置 → 隐私与安全性 → 定位服务 → 天气准，确认权限为「使用App期间」；
  • 室内、地下车库等信号弱环境会造成定位偏移，属于正常现象；
  • 手动选中城市优先级高于自动定位；
  • 国内部分区县定位会匹配到上级地市，建议手动选择乡镇获取更高精度。

2. 为什么天气数据和别的App不一样？

不同App使用的气象数据源、更新频次、站点口径不同，小幅差异属于正常。天气准数据来自公开气象服务商；预报本身有概率性，短期预报准确度更高，多天预报仅作参考。重大灾害预警请以官方气象、应急部门为准。

3. 收不到气象预警通知怎么办？

  1. 系统设置 → 天气准 → 通知，开启允许通知；
  2. 检查专注模式、定时摘要是否拦截推送；
  3. 确认App内该城市预警开关已打开；
  4. 气象预警只有官方发布之后才会推送，无预警期间不会收到消息。

4. 桌面小组件不刷新、空白？

  • 小组件刷新由iOS系统调度，刷新间隔约15–60分钟，无法做到实时；
  • 打开App主动刷新一次，再返回桌面等待；
  • 低电量模式会限制小组件刷新；
  • 长期空白可以删除小组件后重新添加。

5. 保存/分享天气图片失败？

保存图片需要授予「添加照片」权限，App仅具备写入相册权限，不会读取相册其他图片。保存失败同时检查手机存储空间。

6. 字号、温度单位怎么修改？

App内设置页切换摄氏度/华氏度，开启大字模式适配阅读。全部设置保存在本机本地，不上传服务器。

7. 闪退、卡顿如何处理？

  1. 更新App与iOS系统到最新版；
  2. 彻底关闭后台重开App；
  3. 卸载重装（本地城市列表会清空，请留意）；
  4. 仍异常，请发邮件附带设备型号、系统版本、App版本、问题截图反馈。
提示：天气数据仅供出行参考，不可作为工程、航海、防灾避险等专业决策依据。灾害预警请优先遵从当地应急与气象部门通告。

FAQ

  • Wrong location: Go to Settings → Privacy & Security → Location Services, set permission to While Using the App. Poor GPS signal indoors may cause offset. You can add cities manually.
  • Weather discrepancy: Different data providers lead to minor differences. Forecasts are probabilistic, for reference only.
  • No alert notification: Enable notifications in system settings and inside the app. Alerts are sent only when meteorological authorities issue warnings.
  • Widget not updating: iOS controls widget refresh schedule (15–60 min). Open the app to trigger refresh manually.
  • Cannot save image: Grant Add Photos permission. The app cannot read your existing photos.
